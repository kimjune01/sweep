# Repo Hypotheses

Per-repo hypothesis graphs maintained by the [/sweep](../skills/sweep.md) /
[/triage](../skills/triage.md) / [/investigate](../skills/investigate.md)
pipeline. One file per `<owner>-<repo>` the pipeline has touched.

Each file contains some mix of:
- **Repo profile** — review culture, merge patterns, AI policy, eviction
  triggers
- **PR hypothesis traces** — the H0/H1/... reasoning behind specific PRs:
  what was perturbed, what trajectory the evidence took, what was killed,
  what was confirmed
- **Annotations** — frank notes on maintainer behavior, competing PRs,
  scoring decisions

Published verbatim. Stale entries are not pruned.

Linked from PR comments as the underlying reasoning trace when reviewers
ask "where did that investigation come from?"
